# m2r-email-api

Servico backend M2RIA responsavel pelo envio de emails da plataforma (imediato e agendado), com suporte a multiplos providers (SMTP, SendGrid) e templates via Handlebars.

## Como rodar local

```bash
npm install && npm run dev
```
